# 🌐 Nexus - Modern Landing Page

A modern, clean, and responsive landing page built using **HTML, CSS, and JavaScript**.
This project showcases a stylish UI with smooth layout and typography.

---

## 🚀 Live Demo

👉 https://anjali-verma042.github.io/NEXUS-Landing-Page/

---

## 📌 Features

* ✨ Modern and clean UI design
* 📱 Fully responsive layout
* 🎯 Navigation bar (Home, About, Services, Contact)
* 🎬 Hero section with slider
* 🔘 Call-to-action buttons
* 🎨 Custom fonts and styling

## 🛠️ Tech Stack

* HTML5
* CSS3
* JavaScript
